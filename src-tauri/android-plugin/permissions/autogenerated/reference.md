## Default Permission

Everything Quicky's page needs: widgets, reminders, queued widget and notification actions, the Quick Settings tile

#### This default permission set includes the following:

- `allow-widgets`
- `allow-schedule`
- `allow-actions`
- `allow-permission`
- `allow-leave`
- `allow-tile`
